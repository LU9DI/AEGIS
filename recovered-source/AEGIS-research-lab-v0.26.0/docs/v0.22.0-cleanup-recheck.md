# MALEBOLGE v0.22.0 — cleanup and scheduler recheck

Date: 2026-10-09

## Cleanup regression found and fixed

The network-impairment benchmark could snapshot proxy connection counters before relay/shaper teardown had fully drained. This made cleanup results timing-dependent and could leave an unclosed stream writer in a test path. The benchmark now waits for relay connections, active duplex streams, and all proxy connection counters to reach zero before recording cleanup metrics. The TCP proxy tests explicitly close the client writer and wait for active connections to drain before shutdown.

## Validation

Command:

```sh
PYTHONPATH=src python -W error::ResourceWarning -m unittest discover -s tests -q
```

Result: **141 tests passed** in 22.701 seconds, with `ResourceWarning` treated as an error. This is stronger than the previous run, where the suite passed but emitted resource warnings.

## Scheduler A/B recheck

Raw data: `../MALEBOLGE-v0.22.0-recheck-cleanup.json` (distributed separately with this report).

Configuration: loopback profile; 2 and 4 simultaneous equal-size streams; 3 trials per scheduler/count; 128 KiB per stream; 16 KiB write chunks; pipeline depth 4; paired order rotated by trial.

| Streams | Baseline median goodput | Round-robin median goodput | Goodput delta | p95 latency delta | Jain delta |
|---:|---:|---:|---:|---:|---:|
| 2 | 194.29 Mbps | 202.46 Mbps | +4.21% | +2.08% | -0.000157 |
| 4 | 209.95 Mbps | 176.03 Mbps | -16.15% | +20.37% | -0.000165 |

Integrity, relay observability, relay teardown, and proxy teardown checks passed in all runs.

## Decision

**Do not promote round-robin scheduling to the default.** Results are workload-dependent: a small median goodput gain for 2 streams, but a material regression for 4 streams. Jain index is already near 1.0 in these equal-size finite transfers and does not demonstrate improved interactive responsiveness. Keep the scheduler opt-in and preserve v0.22.0 as the reference version.

## Limits

These are same-host IPv4 loopback tests with a user-space TCP byte-stream shaper. They do not simulate packet loss, real WAN congestion, retransmission dynamics, or an adversary capable of global traffic observation. This protocol remains experimental and unaudited.
